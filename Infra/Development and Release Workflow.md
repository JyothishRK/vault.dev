UAT Workflow

1. Raise PR to vc-uat.
2. Once PR is raised, automated scans start:
    * License Check
    * Syft Scan
    * SonarQube Analysis
3. After all quality gates pass:
    * PR becomes eligible for merge.
4. Any authorized developer can merge after validations pass.
5. After PR merge:
    * GitHub Actions deployment workflow triggers automatically. ^XqsvRGSP

vc-prod-base Workflow

1. After product signoff:
    * Raise PR from feature branch to vc-prod-base.
2. Mandatory review from approval team.
3. Verify:
    * Stable code state
    * Required scans passed (verify from UAT scans)
    * Deployment readiness
4. Once approved:
    * Merge PR to vc-prod-base. ^kOtEmGs7

PROD Workflow

1. Raise PR from vc-prod-base to vc-prod.
2. Once PR is raised, automated scans start:
    * License Check
    * Syft Scan
    * SonarQube Analysis
3. After all quality gates pass:
    * PR becomes eligible for merge.
4. Before merging:
    * Create stable backup branch using deployment image tag/version.
5. Only Admin/Release team members can merge the PR.
6. After PR merge:
    * GitHub Actions deployment workflow triggers automatically. ^1m78J7eg
