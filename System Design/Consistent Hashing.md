## Text Elements
Rehashing problem:
-----
- When n cache servers are present, we use the following hash method:
    - serverIndex = hash(key) % N
    - where N is size of server pool.
- This works fine when the number of servers(N) remains constant.
- But when a server goes offline, the serverIndex recompute will point to wrong servers - causing unusual cache misses. ^fJ4aRcCv
