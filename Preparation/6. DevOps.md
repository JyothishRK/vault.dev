# Excalidraw Data

## Text Elements
Linux Filesystem:
----

/
Root filesystem

/home
User home directories

/root
Root user’s home

/etc
Configuration

/var
Variable data/logs

/var/log
Logs

/tmp
Temporary files

/usr
User-space programs/libraries

/bin
Essential commands

/sbin
System administration commands

/opt
Optional software

/proc
Kernel/process information

/dev
Device files ^bRVLfLyM

Permissions:
----

-    rwx    r-x    r--
│     │      │      │
│   owner   group  others
│
file

- r = 4, w = 2, x = 1
- chmod - change perms
- chown - change owner, can add group ownership as well
    - chown john file.txt
    - chown john:developers file.txt
- chgrp - changes group ownership alone
    - chgrp developers app.log
        - This changes:
            -rw-r--r-- john users app.log
            -rw-r--r-- john developers app.log

 ^iiCUhu8s

Command Chanining:
----

command1 && command2 -> Run second if first succeeds

command1 || command2 -> Run second if first fails

command1 ; command2 -> Run both regardless ^AWORsrbF

Process monitoring:
----
 ^kaCkc8rT
