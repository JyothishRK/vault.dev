----
1. Mesh
    - No of cables: n * (n - 1) / 2
    - No of ports: (n - 1) per device
    - Reliability: Highest
    - Cost: Highest (based on cable)
    - Security: Yes
    - Disadv : High maintenance
    - Point to point comms - dedicated communication.
2. Star
    - No of cables: n
    - No of paths: 1 per device
    - Reliability: Single point of failure at hub
    - Cost: Normal
    - Security: No
    - Point to point comms.
3. Bus
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
    - Multipoint network - high chances of collision
4. Ring
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
5. Hybrid ^SdSNew8b

Circuit Switching:
----
- Dedicated path
- In order -> data transmission
- Contiguous flow
- Less efficiency
- Less delay
- Total time = Setup time + Transmission Time (TT) + Propagation delay (PD) + Tear down time.
 ^uD9V5LY2

Packet Switching:
----
- Data transferred in packets
- Data link & Network layer
- 2 Types:
    - Datagram service -> Network layer
    - Virtual circuit -> Data link layer
- Store & forward architecture
- More efficient
- More delay
- Pipelining is used
- Total time = n (no of switches) * Transmission Time (TT) + Propagation delay (PD)  ^zWFKxyr0

Datagram Switching Vs Virtual Circuit:
----
- Datagram Switching:
    - Connectionless
    - No reservation
    - Out of order possible
    - High overload
    - More Packet loss
    - Used in internet

- Virtual circuit:
    - Connection oriented
    - Reservation
    - Same order
    - Less overhead
    - Less Packet loss
    - Used in ATM, X.25

- More efficiency in Datagram
- Cost effective is Datagram ^Sk8bwHp0

- Store & forward ^fwLytahA
