----
1. Mesh
    - No of cables: n * (n - 1) / 2
    - No of ports: (n - 1) per device
    - Reliability: Highest
    - Cost: Highest (based on cable)
    - Security: Yes
    - Disadv : High maintenance
    - Point to point comms - dedicated communication.
2. Star
    - No of cables: n
    - No of paths: 1 per device
    - Reliability: Single point of failure at hub
    - Cost: Normal
    - Security: No
    - Point to point comms.
3. Bus
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
    - Multipoint network - high chances of collision
4. Ring
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
5. Hybrid ^SdSNew8b

Circuit Switching:
----
- Dedicated path
- In order -> data transmission
- Contiguous flow
- Less efficiency
- Less delay
- Total time = Setup time + Transmission Time (TT) + Propagation delay (PD) + Tear down time.
 ^uD9V5LY2

Packet Switching:
----
- Data transferred in packets
- Data link & Network layer
- 2 Types:
    - Datagram service -> Network layer
    - Virtual circuit -> Data link layer
- Store & forward architecture
- More efficient
- More delay
- Pipelining is used
- Total time = n (no of switches) * Transmission Time (TT) + Propagation delay (PD)  ^zWFKxyr0

Datagram Switching Vs Virtual Circuit:
----
- Datagram Switching:
    - Connectionless
    - No reservation
    - Out of order possible
    - High overload
    - More Packet loss
    - Used in internet

- Virtual circuit:
    - Connection oriented
    - Reservation
    - Same order
    - Less overhead
    - Less Packet loss
    - Used in ATM, X.25

- More efficiency in Datagram
- Cost effective is Datagram ^Sk8bwHp0

Data link Layer:
----

- Between Physical and Network Layer
- Works within the same network - using physical / MAC address.
- Functionalities:
    - Hop to Hop / Node to Node delivery
    - Flow control -> protocols:
        - Stop and Wait
        - Go back N
        - Selective repeat
    - Error control (Hop to Hop)
        - CRC - Cycle redundancy check (Used in data link layer)
        - Checksum (Used in Transport layer)
        - Parity
    - Access control
        - CSMA/CD (Carrier sense multiple access with Collision detection)
        - Aloha:
            - Pure Aloha
            - Slotted Aloha
        - Token ring
    - Physical address (MAC)
- Packets divided into fixed size "frames". Frames are used within data link layer.
 ^SDYtJtlD

Framing:
----
- Framing : Pack bits into frames.
- A frame is a character-oriented protocol.
- Flag are used to extract data from the incoming data.
- Data present between flags are considered as data. ^LX4bGcNV

Error Detection & Correction:
----
- Types of error:
    - Single bit error - only 1 bit affected
    - Burst error - more than 1 bit affected
- Detection
    - Simple parity (Even, odd)
    - 2D parity check
    - Checksum
    - CRC (Cycle redundancy check)
- Correction:
    - Hamming code ^VFMaRPXj

Flow control Protocols:
----
- Stop and wait:
    - Only 1 frame at a time
    - Sender window = 1
    - Receiver window = 1
    - efficiency = 1 / (1 + 2 * x), where x = propagation delay / trasmission time.
    - Retransmission = 1
    - Available sequence number (ASN) = Ws + Wr = 2

- Go back N:
    - Multiple frames
    - Sender window = 2^k - 1 , k is number of bits to represent window size
    - Receiver window = 1
    - efficiency = (2^k - 1) * (1 / (1 + 2*x))
    - Commulative ACK
    - Retransmission = 2^k - 1

- Selective repeat:
    - Multiple frames
    - Sender window = 2^k - 1
    - Receiver window = 2^k - 1
    - efficiency = (2^k - 1) * (1 / (1 + 2*x))
    - Commulative & Independent ACK
    - Retransmission = 1
    - Receiver will send neg ACK for sender to send the packet again (time saving)

 ^1A8zfU9K

Multiple Access control Protocols (MAC)
----

- Random access control:
    - Aloha
        - Pure aloha
        - Slotted aloha
    - CSMA
    - CSMA/CD or CSMA/CA
        - CD - Collision detection
        - CA - Collision avoidance
- Control access:
    - Polling
    - Token passing
- Channelization protocols:
    - FDMA - Frequency division multiple access
    - TDMA - Time divided multiple access ^ettia7S2

Parity:
----
- Least expensive method
- Used for error detection
- Types:
    - Even parity : No of 1s should be even -> if even add "0" else "1"
    - Odd parity: No of 1s should be odd -> if odd add "0" else "1"
- Can detect all single bit errors.
- Can detect odd no of bit errors. ^8nAC1Feh

Hamming Distance:
----
- Codeword = data + parity bit
- XOR operation on 2 code words -> Count the no of 1st present in result.
- Minimum Hamming Distance = d -> it can edit error till (d-1) bits. 
- E.g.
    00000
    00011
    -> Min Hamming distance = 2. -> can detect till 1 bit error.       ^rzgjfpBV

Cyclic Redundancy Check:
----
- Used for error detection
- Most widely used
- Single error, odd number of error and burst error upto error length equal to power of the polynomial degree.
- Total bits = m + r
    - m -> message bits
    - r -> random bits
 ^ghEfMEjW
