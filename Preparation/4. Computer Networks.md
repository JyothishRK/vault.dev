## Text Elements
Communication:
----
1. Input message
2. Input Transducer -> Converts message to energy
3. Transmitter -> Amplifier + Modulation + Encoding
4. Channel -> Medium (Contains Noise, Attenuation, Distortion)
5. Receiver -> Demodulation, Decoding
6. Output Transducer -> Converts signal to original
7. Output message ^yyde4GQf

Network Types:
----
1. PAN - Personal area network, 100m, Bluetooth
2. LAN - Local, 2km, Ethernet & Wifi
3. CAN - Campus, 1-5km, Ethernet 
4. MAN - Metropolitan, 5-50km, FDDI CDDI ATM
5. WAN - Wide - > 50km, Leased line & Dial UP ^uYTgyZfy
