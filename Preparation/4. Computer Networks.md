## Text Elements
Communication:
----
1. Input message
2. Input Transducer -> Converts message to energy
3. Transmitter -> Amplifier + Modulation + Encoding
4. Channel -> Medium (Contains Noise, Attenuation, Distortion)
5. Receiver -> Demodulation, Decoding
6. Output Transducer -> Converts signal to original
7. Output message ^yyde4GQf

Network Types:
----
1. PAN - Personal area network, 100m, Bluetooth
2. LAN - Local, 2km, Ethernet & Wifi
3. CAN - Campus, 1-5km, Ethernet 
4. MAN - Metropolitan, 5-50km, FDDI CDDI ATM
5. WAN - Wide - > 50km, Leased line & Dial UP ^uYTgyZfy

FDDI - Fibre Distributed Data Interface
CDDI - Copper Distributed Data Interface
ATM - Asynchronous Transfer Method ^WRhekd2n

Network Topologies:
----
1. Mesh
    - No of cables: n * (n - 1) / 2
    - No of ports: (n - 1) per device
    - Reliability: Highest
    - Cost: Highest (based on cable)
    - Security: Yes
    - Disadv : High maintenance
    - Point to point comms - dedicated communication.
2. Star
    - No of cables: n
    - No of paths: 1 per device
    - Reliability: Single point of failure at hub
    - Cost: Normal
    - Security: No
    - Point to point comms.
3. Bus
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
    - Multipoint network - high chances of collision
4. Ring
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
5. Hybrid ^SdSNew8b

Latency vs Throughput vs Bandwidth:
----

- Bandwidth
    - Volume of data that can be transferred.
    - Mbps
- Throughput
    - At any particular time, how much data is actually transferred from source to destination.
- Latency
    - Time taken for data to reach from source to destination.
    - Propagation delay ? ^vmN0o3OB

OSI Model:
----
- Physical
- Data Link
- Network
- Transport
- Session
- Presentation
- Application ^XjFzFak5
