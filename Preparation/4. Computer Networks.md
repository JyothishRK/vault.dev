1. Mesh
    - No of cables: n * (n - 1) / 2
    - No of ports: (n - 1) per device
    - Reliability: Highest
    - Cost: Highest (based on cable)
    - Security: Yes
    - Disadv : High maintenance
    - Point to point comms - dedicated communication.
2. Star
    - No of cables: n
    - No of paths: 1 per device
    - Reliability: Single point of failure at hub
    - Cost: Normal
    - Security: No
    - Point to point comms.
3. Bus
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
    - Multipoint network - high chances of collision
4. Ring
    - No of cables: n + 1
    - No of paths: 1 per device
    - Reliability: Single point of failure backbone wire
    - Cost: Normal (more than star)
    - Security: No
5. Hybrid ^SdSNew8b

----
- Types of error:
    - Single bit error - only 1 bit affected
    - Burst error - more than 1 bit affected
- Detection
    - Simple parity (Even, odd)
    - 2D parity check
    - Checksum
    - CRC (Cycle redundancy check)
- Correction:
    - Hamming code ^VFMaRPXj

----
- Stop and wait:
    - Only 1 frame at a time
    - Sender window = 1
    - Receiver window = 1
    - efficiency = 1 / (1 + 2 * x), where x = propagation delay / trasmission time.
    - Retransmission = 1
    - Available sequence number (ASN) = Ws + Wr = 2

- Go back N:
    - Multiple frames
    - Sender window = 2^k - 1 , k is number of bits to represent window size
    - Receiver window = 1
    - efficiency = (2^k - 1) * (1 / (1 + 2*x))
    - Commulative ACK
    - Retransmission = 2^k - 1

- Selective repeat:
    - Multiple frames
    - Sender window = 2^k - 1
    - Receiver window = 2^k - 1
    - efficiency = (2^k - 1) * (1 / (1 + 2*x))
    - Commulative & Independent ACK
    - Retransmission = 1
    - Receiver will send neg ACK for sender to send the packet again (time saving)

 ^1A8zfU9K
