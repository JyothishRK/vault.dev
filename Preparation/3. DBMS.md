Functional Dependency:
----
- 2 types:
    - Trivial: if x -> y, and y is a subset of x.
    - Non-trivial: x -> y, and x intersection y is null.
- Properties of FD:
    - Reflexivity: if y is subset of x : x -> y
    - Augmentation: if x -> y : xz -> yz
    - Transitive: if x -> y && y -> z : x -> z
    - Union: if x -> y && x -> z : x -> yz
    - Decomposition: if x -> yz : x -> y && x -> z
    - Pseudo-transitivity: if x -> y && wy -> z : wx -> z
    - Composition: if x -> y && z -> w : xz -> yw ^KnRzbDOl

1 NF:
----
- Table should not contain any multivalued attributes

2 NF:
----
- Table must be in 1 NF
- All non prime attributes should be fully functional dependent on the candidate key.

3 NF:
----
- Table must be in 2 NF
- There should not be any transitive dependency in the table.

BCNF: (Boyce Codd Normal form)
----
- Table must be in 3 NF
- LHS of each functional dependency should be Candidate key or Super key. ^2nQVJaZc
