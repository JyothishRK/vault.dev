    fork();

----
- Process:
    - System call involved
    - OS treats different process differently
    - Diff process have diff copies of data, file, code
    - Context switch is slower
    - Blocking a process will not block another process
    - Independent

- Threads:
    - There is no system call involved
    - All user level threads treated as single task by OS
    - Share same copy of code & data
    - Context switching is faster
    - Blocking a process will block entire process
    - Interdependent
 ^yqXWmr8B

----
- User level:
    - Managed by user level library
    - Typically fast
    - Context switching is faster
    - If 1 user level thread performs blocking operation then entire process gets blocked.

- Kernel level:
    - Managed by OS
    - Slower than User
    - Context switching is slower
    - If one thread blocked, no effect on others ^kB7toQY9
