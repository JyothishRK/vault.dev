Critical Section:
----
- Part of the program where the shared resources access by various processes.
- If 2 program run the critical section at the same time, it causes malformed data -> Racing condition.

- Conditions for Synchronization:
    - Mutual exclusion
    - Progress
    - Bounded wait
    - No assumption related to hardware & speed.

- Mutual exclusion: Only one process can run the critical section at a time.

- Bounded wait: Wait time should be bounded (not infinite)

- Critical solution solutions:
    - Locks
    - Test and Set Instruction
    - Turn variable (Strict alteration) ^6VUShsAW

Locks:

- Using lock variable
- Executes in user mode.
- Multiprocess solution.
- No mutual exclusion guarentee.

Semaphore:
----
- Integer variable which is used in mutual exclusion manner in various concurrent cooperative process in order to achieve synchronization.
- 2 Types:
    - Counting - -inf to +inf
    - Binary - 0 or 1
- Entry code -> P(), Down, Wait
- Exit code -> V(), up, Signal


Down (Semaphore S) {
    S.value = S.value - 1;
    if (S.value < 0) {
        Put process (PCB) in Suspend list Sleep(),
    }
    else {
        return;
    }
}


Up (Semaphore S) {
    S.value = S.value + 1;
    if (S.value <= 0) {
        Select a process from Suspend List Wake_up(),
    }
} ^KYf7fFMK

Binary Semaphore:

- Values are only 0 or 1.
