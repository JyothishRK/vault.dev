JavaScript:

Web APIs:
- 2 Types:
    - Callback based
    - Promises based

* Callback based:
    - When these are used, the function callbacks are pushed into the Task Queue (Callback Queue).
    - The Event Loop checks if the call stack is empty and process the items from Task Queue.

* Promises based:
    - When these are used, the callbacks or function body is pushed into the Micro task Queue.
    - The Event Loop checks if the call stack is empty and process the items from Micro task Queue.

* Priority:
    - Micro task queue > Task queue ^FWOshOiY
