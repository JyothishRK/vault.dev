OOPS:
----

- Procedural programming:
    - function -> data
- OOPS:
    - Object -> Owns data -> Owns behavior.
- Each object has:
    - State: What it has (properties)
    - Behavior: What is does (function methods)
- What is Object:
    - Object is an entity with identity, state and behavior.

- Benefits of OOP:
    - Encapsulation: protects their own data.
    - Reusability: Reuse classes across multiple features.
    - Maintainability: Changes stay localized.
    - Extensibility: Add new function without rewriting everything.
    - Modularity: Large system = small focused components.

 ^PGFQIMrL

Access Modifiers:
----

- private
    - Data and methods accessible inside class.
- public
    - Data and methods accessible to everyone.
- protected
    - Data and methods accessible inside class & to its derived class.

- By default, access is private.
 ^IYGwdzUx

- Wrapping up data and member functions in a single unit called class.
- Used in data hiding -> using private access modifier.
 ^GEYAWljl

- Automatically invoked during object creation - for init.
- Same name as class and no return type.
- Only called once (automatically during creation)
- Memory allocation happens when constructor is called.
- 3 types of constructor:

- Constructor overloading is an example of polymorphism.

This pointer:
---

- Special pointer that points to the current object.
- Example:
    this->name = name;
- this->prop is same as *(this).prop .

Copy constructor:
---

- Special constructor used to copy properties from one object to another.
- Default copy constructor always present.
    - Teacher t2(t1); // Default copy constructor.
 ^GAaMow9a

- Shallow copy: copies all the member values from one object to another.
- Default constructor -> Shallow copy.
- Issue with Shallow copy:
    - Occurs during dynamic memory allocation.(In heap)
    - For the dynamically allocated memory - the variable changes will reflect in both objects since address is stored.

- Deep copy: Not only copies member values but also copies of any dynamically allocated memory that members point to.

Student {
public:
    string name;
    double* cgpaPtr;

    // Shallow copy
    Student(Student &obj) {
        this->name = obj.name;
        this->cgpaPtr = obj.cgpaPtr;
    }

    // Deep copy
    Student(Student &obj) {
        this->name = obj.name;
        // Again allocate memory for new object
        // So it references the new address
        cgpaPtr = new double;
        *cgpaPtr = obj.cgpaPtr;
    }

}; ^d4GcMyel

- Opposite of destructor.
- Only removes statically allocated memory.

// Destructor
~Student() {
    delete cgpaPtr;
}

- For dynamically allocated memory, we need to clear manually using Destructor.
- This is done to get rid of memory heap. ^VMJOxcJ4

- Properties & member functions of the base class are passed on to the derived class.
- Used for code reusability.
- Constructor execution order:
    1. Base class.
    2. Child class.
- Destructor execution order:
    1. Child class.
    2. Base class.


class Person {
public:
    string name;
    int age;

    Person(string name, int age) {
        this->name = name;
        this->age = age;
    }
};

class Student : public Person{
    // Name, age and roll no.
public:
    int rollNo;

    Student(string name, int age, int rollNo) : Person(name, age) {
        this->rollNo = rollNo;
    }
}; ^3jfPZrKO

Abstraction:
----

- Hiding all unnecessary details & showing only important parts.
- Can be done using 2 ways:
    1. Access modifiers.

Abstract classes:
--

- Used to provide a base class from which other classes can be derived - Blueprint for other classes.
- They can't be instantiated and are meant to be inherited.
- Typically used to define an interface for derived classes.

// Abstract class
class Shape {
    virtual void draw() = 0; //pure virtual function.
};

class Circle : public Shape {
public:
    void draw() {
        cout << "Drawing circle" << endl;
    }
}; ^3Jf0ujYt
